# Spec Delta

## ADDED Requirements

### Requirement: Тип плательщика ученика
Система SHALL хранить у ученика обязательный тип плательщика — физическое или
юридическое лицо. Допустимы ровно два значения: физлицо (`individual`) и
юрлицо (`legal_entity`). При создании ученика без явного выбора тип SHALL быть
физлицом. Значение вне допустимого набора MUST отклоняться с сообщением об
ошибке, а не сохраняться.

#### Scenario: По умолчанию физлицо
- **WHEN** создаётся ученик, и тип плательщика не выбран
- **THEN** ученик сохраняется с типом «физлицо»

#### Scenario: Юрлицо сохраняется
- **WHEN** репетитор выбирает «Юрлицо» и сохраняет карточку
- **THEN** тип плательщика сохраняется, а при повторном открытии формы отмечено
  «Юрлицо»

#### Scenario: Недопустимое значение отклоняется
- **WHEN** в поле типа плательщика приходит значение вне пары
  физлицо/юрлицо
- **THEN** карточка не сохраняет это значение, а форма показывает сообщение
  «Выберите тип плательщика: физлицо или юрлицо.»

#### Scenario: Существующие ученики
- **WHEN** миграция применяется к базе с ранее созданными учениками
- **THEN** все прежние записи получают тип «физлицо» без потери данных

### Requirement: Тип плательщика в форме и карточке
Переключатель «Физлицо / Юрлицо» SHALL располагаться в форме ученика рядом с
выбором плательщика, а выбранный тип SHALL отображаться на странице карточки
ученика. Тип плательщика SHALL быть независим от выбора плательщика-контакта:
плательщиком может быть и сам ученик, и привязанный контакт.

#### Scenario: Переключатель рядом с выбором плательщика
- **WHEN** открыта форма ученика на вкладке «Общее»
- **THEN** в секции «Плательщик» под полем «Кто оплачивает занятия» находится
  переключатель «Физлицо / Юрлицо», по умолчанию отмечено «Физлицо»

#### Scenario: Тип в карточке ученика
- **WHEN** у ученика тип плательщика — юрлицо
- **THEN** страница карточки показывает рядом с плательщиком подпись «Юрлицо»

#### Scenario: Тип независим от плательщика-контакта
- **WHEN** у ученика не выбран плательщик-контакт (платит сам ученик), но тип
  плательщика — юрлицо
- **THEN** оба значения сохраняются независимо: плательщик остаётся «сам
  ученик», тип — «юрлицо»
