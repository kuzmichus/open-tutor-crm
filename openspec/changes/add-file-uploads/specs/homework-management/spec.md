# Spec Delta

## REMOVED Requirements

### Requirement: Поля ДЗ без файлов и автоматики

Панель ДЗ SHALL содержать кнопку «Прикрепить файл» как неработающую заглушку: файлы в этой итерации не загружаются, сохраняются и не отдаются. Чекбокс «Учитывать дедлайн» SHALL сохранять своё значение, но напоминания и автоматический статус по дедлайну в этой итерации MUST NOT выполняться.

#### Scenario: Кнопка файлов не загружает файлы
- **WHEN** на вкладке «ДЗ» нажата кнопка «Прикрепить файл»
- **THEN** файл не выбран и не сохранён

#### Scenario: Флаг дедлайна сохраняется без поведения
- **WHEN** сохранение ДЗ выполнено с включённым чекбоксом «Учитывать дедлайн»
- **THEN** признак учёта дедлайна сохранён, автоматический статус ДЗ не изменён

## ADDED Requirements

### Requirement: Прикрепление файлов к ДЗ

Панель ДЗ SHALL принимать несколько файлов за одну отправку и SHALL показывать
список уже прикреплённых файлов с именем, размером, ссылкой на скачивание и
кнопкой удаления. Файлы SHALL храниться отдельно от записи ДЗ и привязываться к
ней отдельной связью с сохранением порядка.

#### Scenario: Прикрепление файлов при сохранении ДЗ
- **WHEN** на вкладке «ДЗ» выбраны два файла и нажата «Сохранить ДЗ»
- **THEN** оба файла сохранены и показаны в списке панели в порядке выбора

#### Scenario: Повторное сохранение не теряет файлы
- **WHEN** ДЗ с прикреплёнными файлами сохранено повторно без выбора новых файлов
- **THEN** ранее прикреплённые файлы остаются в списке

#### Scenario: Удаление файла из панели
- **WHEN** репетитор нажимает кнопку удаления у прикреплённого файла
- **THEN** файл исчезает из списка панели, запись ДЗ и остальные файлы не меняются

### Requirement: Ограничения файлов задаются capability file-storage

Загрузка и удаление файлов ДЗ MUST подчиняться требованиям capability
`file-storage`: список разрешённых расширений, лимит размера, изоляция доступа и
временные ссылки S3.

#### Scenario: Файл сверх лимита
- **WHEN** на вкладке «ДЗ» выбран файл больше `FILES_MAX_SIZE_MB`
- **THEN** файл не сохранён, панель показывает сообщение об ошибке

### Requirement: Ошибка загрузки файла отменяет сохранение ДЗ

Ошибка загрузки любого файла MUST отменять сохранение ДЗ целиком: запись ДЗ не
создаётся и не обновляется, форма показывает сообщение об ошибке.

#### Scenario: Ошибка файла отменяет сохранение ДЗ
- **WHEN** среди выбранных файлов есть файл запрещённого расширения или слишком большой
- **THEN** ни один файл не сохранён, запись ДЗ не изменена, форма показывает сообщение об ошибке

### Requirement: Файлы ДЗ видны ученику и родителю

Карточка ДЗ в кабинете ученика и вкладка ребёнка в кабинете родителя SHALL
показывать прикреплённые файлы со ссылкой на скачивание.

#### Scenario: Ученик видит файлы задания
- **WHEN** ученик открывает карточку ДЗ с прикреплёнными файлами
- **THEN** он видит список файлов и может их скачать

#### Scenario: Родитель видит файлы задания
- **WHEN** родитель открывает вкладку «Домашние задания» ребёнка
- **THEN** он видит прикреплённые к ДЗ файлы со ссылкой на скачивание

### Requirement: Флаг дедлайна сохраняется без поведения

Чекбокс «Учитывать дедлайн» SHALL сохранять своё значение, но напоминания и
автоматический статус по дедлайну MUST NOT выполняться.

#### Scenario: Флаг дедлайна сохраняется без поведения
- **WHEN** сохранение ДЗ выполнено с включённым чекбоксом «Учитывать дедлайн»
- **THEN** признак учёта дедлайна сохранён, автоматический статус ДЗ не изменён
