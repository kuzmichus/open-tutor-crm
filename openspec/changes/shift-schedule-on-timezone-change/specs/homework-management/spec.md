# Spec Delta

## ADDED Requirements

### Requirement: Смена часового пояса переносит сроки сдачи ДЗ
При смене часового пояса педагога сроки сдачи домашних заданий его уроков SHALL сохранять своё настенное время: значение срока в хранилище SHALL пересчитываться под новую зону. ДЗ без срока сдачи MUST оставаться без срока; ДЗ другого репетитора MUST NOT затрагиваться.

#### Scenario: Срок сохраняет настенное время
- **WHEN** у педагога в зоне UTC+04 задан срок сдачи 18:00 и он меняет зону на UTC+07
- **THEN** срок показывается на 18:00 в новой зоне, а в хранилище стоит 11:00 UTC

#### Scenario: ДЗ без срока
- **WHEN** у педагога есть ДЗ без срока сдачи и он меняет часовой пояс
- **THEN** срок остаётся незаданным, ошибки нет

#### Scenario: Чужие ДЗ не меняются
- **WHEN** педагог меняет часовой пояс
- **THEN** сроки ДЗ другого репетитора остаются прежними
