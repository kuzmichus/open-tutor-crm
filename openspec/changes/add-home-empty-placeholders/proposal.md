# Proposal

## Why

Пустые блоки «Расписание на сегодня» и «Недавние платежи» на главной
показывали одну серую строку текста («На сегодня уроков нет», «Платежей пока
нет»). По референсу задачи TOCRM-64 пустой блок должен выглядеть как
осмысленная заглушка: иконка, заголовок и подсказка о следующем действии.
Сейчас блок визуально «схлопывается» и не подсказывает новому репетитору,
что делать дальше.

## What Changes

- `app/tutor/templates/tutor/home.html`: вместо `<p class="home-empty">` —
  заглушка из иконки Lucide, заголовка и подсказки. Расписание — `calendar`,
  «Нет запланированных уроков» / «Добавьте урок в календаре». Платежи —
  `credit-card`, «Нет платежей» / «Платежи появятся здесь».
- `app/static/styles.css`: `.home-empty` становится колонкой по центру с
  минимальной высотой; новые классы `.home-empty__icon`, `.home-empty__title`,
  `.home-empty__text` на токенах темы (работают в тёмной теме).
- `tests/test_home.py`: тест заглушек пустых блоков (иконка, заголовок,
  подсказка в своей панели) и тест «данные есть — заглушки нет»; тест изоляции
  обновлён под новые подписи.
- `openspec/specs/tutor-dashboard/spec.md`: требование заглушек и обновлённые
  сценарии пустых блоков; `CHANGELOG.md` — запись в `[Unreleased]`.

**Вне области:**

- Счётчики и данные дашборда (`app/tutor/services/dashboard.py`) не меняются:
  правка чисто презентационная.
- Заглушки других блоков (ученики, группы, уроки, финансы) не трогаем — у них
  уже есть `.empty-state` со своими правилами.

## Capabilities

### New Capabilities

— (нет; расширяется существующая `tutor-dashboard`)

### Modified Capabilities

- `tutor-dashboard`: пустые блоки расписания и платежей показывают заглушку с
  иконкой, заголовком и подсказкой вместо строки текста.

## Impact

- `app/tutor/templates/tutor/home.html`, `app/static/styles.css`.
- `tests/test_home.py`.
- `openspec/specs/tutor-dashboard/spec.md`, `CHANGELOG.md`.
- Схема БД, миграции и сервисы не меняются; новые иконки не добавляются —
  `calendar` и `credit-card` уже есть в наборе.
