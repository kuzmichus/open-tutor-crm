# Proposal

## Why

В форме урока есть вкладка «ДЗ», но она — зафиксированная заглушка (спека `lesson-management`, requirement «Вкладка "ДЗ" — заглушка»): поля домашнего задания отсутствуют, задавать и вести ДЗ репетитору негде. Без полей ДЗ урок не закрывает цикл «провёл → задал домашку → принял и проверил», а заявленные в настройках ученика напоминания о ДЗ не имеют данных, с которыми работать.

## What Changes

- Новая таблица `homework` (1:1 с `lessons`, ленивое создание при сохранении ДЗ): задание, срок сдачи, признак учёта дедлайна, статус, ссылка на запись урока, заметка педагога, комментарий педагога.
- Модалка редактирования урока: вкладка «ДЗ» становится активной; панель ДЗ — отдельная форма со своей кнопкой «Сохранить ДЗ» и своим POST-эндпоинтом (вложенные `<form>` в HTML запрещены, футер модалки выносится наружу обеих форм).
- Модалка создания урока: вкладка «ДЗ» видна, но остаётся неактивной (ДЗ задаётся после урока).
- Статусы ДЗ — закрытый список из пяти значений: «Не задано» (по умолчанию), «Задано», «Сдано», «Проверено», «Не выполнено»; любой статус ставится вручную.
- Пустое «Задание» при сохранении ДЗ — ошибка: ДЗ не создаётся и не сохраняется.
- Вне scope (следующие итерации): файлы-вложения, напоминания о ДЗ, автоматический статус по дедлайну («просрочено»), кабинет ученика (подписи «Увидит ученик в кабинете» и «Ученику не видна» сохраняются как есть, но видимость ученику появится с кабинетом).

## Capabilities

### New Capabilities

- `homework-management`: домашнее задание урока — модель `homework` (1:1 с уроком), поля и статусы ДЗ, сохранение через отдельную форму таба «ДЗ» с валидацией (пустое задание — ошибка), изоляция по репетитору, отсутствие массового применения на серию.

### Modified Capabilities

- `lesson-management`: requirement «Вкладка "ДЗ" — заглушка» заменяется: в редактировании вкладка «ДЗ» активна и открывает панель полей ДЗ, в создании — видна, но неактивна; модалка редактирования содержит две формы (урок и ДЗ) с общим футером.

## Impact

- **Код**: новый доменный подмодуль `app/homework/` (модель, view сохранения/получения ДЗ, сервис разбора формы и контекста, шаблон панели), правки `app/lesson/templates/lesson/_form.html` (две формы, активная вкладка), `app/lesson/services/lesson_form.py` (контекст панели ДЗ), `app/models.py` (регистрация модели), `app/templating.py` (каталог шаблонов homework при необходимости).
- **БД**: миграция Alembic — таблица `homework` с FK на `lessons` (CASCADE при удалении урока/серии).
- **Тесты**: новые `tests/test_homework.py` (сохранение, пустое задание, статусы, чужой урок, отсутствие массового применения); правка `tests/test_lesson_create.py` / `tests/test_lesson_update.py` (вкладка «ДЗ» активна в редактировании, заглушка при создании).
- **Зависимости**: без новых — файлы и multipart-загрузка не используются.
