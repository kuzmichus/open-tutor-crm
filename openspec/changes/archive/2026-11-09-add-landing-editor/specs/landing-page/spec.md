# Spec Delta

## ADDED Requirements

### Requirement: Редактор лендинга

`GET /tutor/landing/editor` SHALL требовать сессию репетитора и быть
доступным только в сингл-режиме; в мульти-режиме MUST отвечать 404. При
отсутствии `draft.html` роут SHALL создавать черновик из шаблона профиля и
открывать его. Страница SHALL быть автономным документом (свой `<html>`,
без `base.html`, сайдбара и общего `app.css`) с верхней панелью
«Сохранить», «Предпросмотр», «Назад к управлению» и контейнером редактора
на весь вьюпорт. Ответ SHALL отдаваться с `Cache-Control: no-store`.

В редактор SHALL попадать содержимое `<body>` черновика без тегов
`<script>` и первый `<style>` черновика; подключение `/static/landing-auth.js`
на странице редактора MUST NOT выполняться.

#### Scenario: Открытие редактора
- **WHEN** включён `SINGLE_MODE`, репетитор вошёл и открывает `/tutor/landing/editor`
- **THEN** ответ 200 с автономной страницей GrapesJS, русскими подписями и телом черновика без скриптов

#### Scenario: Черновика нет
- **WHEN** репетитор открывает редактор, а `draft.html` отсутствует
- **THEN** черновик создаётся из шаблона профиля и открывается в редакторе

#### Scenario: Мульти-режим
- **WHEN** `SINGLE_MODE` выключен
- **THEN** `GET /tutor/landing/editor` и `POST /tutor/landing/draft` отвечают 404 и не создают файлов

### Requirement: Сохранение черновика из редактора

`POST /tutor/landing/draft` SHALL принимать JSON `{html, css}` от
`editor.getHtml()` / `editor.getCss()` и собирать полный документ:
`<!doctype html>`, `<html lang="ru">`, `<meta charset="utf-8">`,
`<meta name="viewport" content="width=device-width, initial-scale=1">`,
`<title>` из текущего черновика (или «{имя} — репетитор»), `<style>{css}</style>`
и тело. Внешняя обёртка `<body>…</body>`, которую возвращает GrapesJS,
SHALL сниматься. Документ MUST записываться в `draft.html`. Ответ SHALL
содержать `{"message": "Сохранено"}` с `Cache-Control: no-store`.

Тег `<script src="/static/landing-auth.js" defer></script>` SHALL
гарантироваться идемпотентно: если маркер `landing-auth.js` уже есть в
документе, документ не меняется; иначе тег вставляется перед последним
`</body>` (без `</body>` — в конец). Повторные сохранения MUST оставлять
ровно один такой тег.

Оформление черновика SHALL переживать круглый трип: сокращённые CSS-свойства
с `var()` загружаются в GrapesJS развёрнутыми в длинные, чтобы CSSOM не
выбрасывал `background: var(--accent)`, `border: … var(--border)` и
`border-radius: var(--radius)`.

#### Scenario: Сохранение правок
- **WHEN** редактор отправляет новый HTML и CSS
- **THEN** `draft.html` содержит новый HTML, CSS в `<style>`, шапку документа, прежний `<title>` и ровно один тег `landing-auth.js`

#### Scenario: Идемпотентность тега
- **WHEN** сохранение выполнено дважды или в HTML уже есть тег `landing-auth.js`
- **THEN** в `draft.html` остаётся ровно один такой тег

#### Scenario: Круглый трип
- **WHEN** репетитор открыл редактор, ничего не менял и нажал «Сохранить»
- **THEN** страница остаётся валидной, `<title>`, точки входа `data-auth`, секции, оформление (цвет CTA, рамки), CSS-переменные и мобильный брейкпоинт сохраняются

### Requirement: Вендоринг GrapesJS и русская локаль

GrapesJS SHALL лежать локально в `app/static/dist/grapesjs/` вместе с CSS и
файлом лицензии; CDN MUST NOT использоваться. Версия SHALL быть
зафиксирована в README рядом с файлами. Русская локаль
`app/static/dist/grapesjs/i18n-ru.js` SHALL определять
`window.grapesjsI18nRu` со структурой ключей en-набора дистрибутива
(ассеты, блоки, устройства, панели, селекторы, стили, трейты, компоненты)
и подключаться с `locale: 'ru'`, `localeFallback: 'en'`; незаведённые
ключи MUST молча уходить в английский.

#### Scenario: Локальные файлы
- **WHEN** открыта страница редактора
- **THEN** GrapesJS CSS и JS загружаются с `/static/dist/grapesjs/`, запросов к CDN нет

#### Scenario: Русский интерфейс
- **WHEN** редактор инициализирован
- **THEN** панели, менеджеры стилей, трейтов, ассетов и устройств подписаны по-русски, а незаведённые ключи показываются по-английски

### Requirement: Кнопка «Редактировать»

На странице управления лендингом кнопка «Редактировать» SHALL быть видна
всегда и вести на `/tutor/landing/editor`; в пустом состоянии редактор сам
создаёт черновик.

#### Scenario: Переход в редактор
- **WHEN** открыта `/tutor/landing`
- **THEN** на странице есть ссылка `/tutor/landing/editor` с текстом «Редактировать»
