# Proposal

## Why

Лендинг уже создаётся из профиля и публикуется, но править его можно только
файлом `draft.html` на диске: визуального редактора нет, кнопка
«Редактировать» скрыта. Репетитору нужен полноэкранный редактор с русским
интерфейсом, который открывает текущий черновик, позволяет менять текст и
разметку мышью и сохраняет результат, не теряя служебный тег подмены входов.

## What Changes

- Вендоринг GrapesJS 0.23.9 (js + css + LICENSE) в
  `app/static/dist/grapesjs/`; CDN не используется. Фактическая лицензия
  дистрибутива — BSD-3-Clause (в задаче указана MIT); сохранён исходный
  текст лицензии, расхождение отмечено в README рядом с файлами.
- Русская локаль `app/static/dist/grapesjs/i18n-ru.js` по структуре
  en-набора дистрибутива: менеджеры ассетов, блоков, устройств, панелей,
  селекторов, стилей, трейтов и компонентов. Незаведённые ключи уходят в
  английский через `localeFallback: 'en'`.
- Новый сервис `app/landing/services/draft_render.py`: извлечение тела и
  первого `<style>` из черновика, удаление `<script>` из тела, сборка
  полного документа с фиксированной шапкой и сохранением `<title>`,
  идемпотентная гарантия тега `/static/landing-auth.js`.
- Новые вьюхи `GET /tutor/landing/editor` и `POST /tutor/landing/draft`
  (`app/landing/views/editor.py`), доступные только в сингл-режиме и только
  с сессией репетитора; при отсутствии черновика он создаётся из шаблона
  профиля.
- Автономный шаблон `app/landing/templates/landing/editor.html`: без
  `base.html` и сайдбара, верхняя панель «Сохранить / Предпросмотр / Назад к
  управлению», контейнер на весь вьюпорт, локальные скрипты GrapesJS.
- Кнопка «Редактировать» на странице управления всегда видна и ведёт в
  редактор.
- Тесты `tests/test_landing_editor.py`: доступ и 404 в мульти-режиме,
  автосоздание черновика, автономность страницы, извлечение тела/CSS,
  сохранение, сохранение `<title>`, идемпотентность тега, круглый трип,
  вендоринг и unit-тесты `draft_render`.

**Вне области:**

- Загрузка картинок из интерфейса редактора (эндпоинт ассетов) — отдельная
  задача; менеджер ассетов переведён, но upload URL не настраивается.
- Сохранение пользовательских `<script>` в теле: GrapesJS их вырезает, а
  тег `landing-auth.js` возвращается отдельно.

## Capabilities

### New Capabilities

— (нет; расширяется существующая `landing-page`)

### Modified Capabilities

- `landing-page`: редактор GrapesJS, русская локаль, разбор и сборка
  черновика, гарантия тега `landing-auth.js`, видимость кнопки
  «Редактировать».

## Impact

- `app/static/dist/grapesjs/*` (новые вендорные файлы).
- `app/landing/services/draft_render.py`, `app/landing/views/editor.py`,
  `app/landing/views/__init__.py`.
- `app/landing/templates/landing/editor.html`,
  `app/landing/templates/landing/page.html`, `app/landing/views/page.py`.
- `tests/test_landing_editor.py`.
- `README.md`, `CHANGELOG.md`, спека `landing-page`.
- `.gitignore` (исключение для `app/static/dist/`).
- Схема БД, миграции и `LANDING_ROOT` не меняются.
