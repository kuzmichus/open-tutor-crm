# Design

## Context

Главная — последняя страница-заглушка каркаса. Вокруг неё всё нужное уже есть: уроки с зонным временем (tutor-timezone), статусы учеников, счёт с операциями (student-finance), недельный календарь с выборкой уроков по цели. Дашборд только собирает готовое.

## Goals / Non-Goals

- Goals: обзор «сегодня и этот месяц» одним экраном; данные только с сервера; зона педагога во всех границах; изоляция по репетитору.
- Non-Goals: редактирование профиля, переходы из карточек и строк, настройки периода, групповые панели, пагинация.

## Decisions

### D1. Границы — настенное время педагога, перевод по отдельности
«Сегодня» — `local_day_bounds`, месяц — та же схема для 1-го числа (design D3 спеки tutor-timezone): прибавление timedelta к UTC-значению ошибалось бы в ночь перевода часов. Платёж, внесённый «вчера» по UTC, но «сегодня» настенными, попадает в сегодняшний доход.

### D2. Счётчик «Запланировано» — из выборки дня, без второго запроса
Расписание дня и карточка «Уроки сегодня» читают один SELECT: у строки есть статус, сумму по статусу считает Python. Второй запрос дублировал бы окно и мог разойтись со списком.

### D3. «Проведено часов» — целые часы, половина округляется вверх
`(минуты + 30) // 60`: 50 минут при простом делении дали бы «0 часов» — обидная точность для обзорной карточки. В расчёт идут только завершённые уроки месяца, индивидуальные и групповые вместе.

### D4. Деньги — только оплаченные платежи
И «Доход за месяц», и «Недавние платежи» берут `kind='payment', status='paid'` — тот же критерий, что у баланса (`BALANCE_PAYMENT_STATUS`). Ожидающий платёж деньгами не стал; суммы со знаком выводит `signed_money` из finance — формат и знак совпадают со счётом ученика.

### D5. Профиль переезжает, а не удаляется
Ссылка `/tutor/profile` уже стояла в футере сайдбара (строка пользователя) и вела на несуществующую страницу. Карточка профиля переезжает туда целиком, включая выход из аккаунта; главная освобождается под дашборд.

### D6. Тинты иконок — свои токены, не цвета статусов уроков
Четыре пары `--stat-*` (синий, зелёный, оранжевый, фиолетовый) в токенах с переопределением тёмной темы: семантика «подсветка карточки» не связана со статусами уроков, а фиолетового в палитре статусов нет вовсе. Компоненты — плоские BEM-селекторы (`stat-card__icon--blue`), модуль tutor добавлен в проверку CSS-теста.

## Risks / Trade-offs

- Кнопка «Обновить» — полный переход на `/tutor/`, без htmx-партиала: страница маленькая, а отдельный маршрут-фрагмент ради одной кнопки дублировал бы выборки.
- Дата платежа без года («21 окт.») неоднозначна в январе для декабрьских платежей — в блоке только последние 5 платежей, риск минимален; полная дата видна в истории счёта.
