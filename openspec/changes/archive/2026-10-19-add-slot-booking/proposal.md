# Proposal

## Why

Календарь умеет создавать только демо-уроки «для себя», но у репетитора есть второй сценарий — предложить свободное окно, на которое ученик может записаться по ссылке. Сейчас такой функциональности нет вообще: нет ни кнопки, ни понятия «свободный слот», ни способа отметить, что окно уже занято.

## What Changes

- Новая кнопка **«Добавить слот»** в панели управления календаря (рядом с «Добавить»): открывает диалог «Новый слот» с датой, временем и длительностью (без выбора ученика — слот свободный для всех).
- После подтверждения в сетке появляется **карточка свободного слота**: визуально отличается от урока (пунктирная рамка, отдельный цвет), подпись «Свободен · запись по ссылке», интервал времени.
- На карточке свободного слота действие **«Записаться»**: в демо-режиме это интерпретация перехода по ссылке записи (сама ссылка `/slot/...` появится с появлением бэкенда) — открывает диалог записи с полями **имя + телефон/Telegram**.
- После подтверждения в диалоге слот в календаре **отмечается занятым**: карточка меняет стиль и подпись на «Занят: \<имя\>», действие записи исчезает, повторная запись невозможна.
- Всё живёт только в DOM (Alpine): без серверных запросов и без БД; слоты исчезают при листании недели — как и демо-уроки.

**Вне объёма этого change:** модель слота в БД, публичная страница `/slot/<токен>`, реальная запись, серверная генерация слотов, слоты в мобильной FAB, перетаскивание слотов.

## Capabilities

### New Capabilities
- `slot-booking`: жизненный цикл свободного слота на недельном календаре — создание через диалог, визуальные состояния «свободен/занят», демо-запись по ссылке с отметкой занятости и DOM-only жизненный цикл.

## Impact

- `app/calendar/templates/calendar/_area.html` — кнопка в тулбаре, диалог «Новый слот», диалог записи, разметка карточки слота.
- `app/static/calendar.js` — состояние слотов, открытие/создание слота, открытие диалога записи и подтверждение записи, рендер карточки слота.
- `app/static/styles.css` — стили карточки «свободен»/«занят» и двух диалогов (светлая/тёмная темы на переменных).
- `tests/test_calendar.py` — SSR-тесты разметки кнопки, диалогов и карточки; статические проверки JS/CSS.
- Спецификация: новая capability-спека `openspec/changes/add-slot-booking/specs/slot-booking/spec.md` (delta, ADDED).
