# Spec Delta

## MODIFIED Requirements

### Requirement: Поле длительности
Длительность урока SHALL выбираться из закрытого списка значений: 30, 35, 40, 45, 50, 55, 60, 65, 70, 75, 90, 105, 120, 150, 180 минут. Иное значение MUST отклоняться валидацией. При создании урока без явно заданной длительности селект SHALL предвыбирать «Длительность урока по умолчанию (мин)» из настроек профиля (вкладка «Календарь»); значение настройки вне закрытого списка MUST заменяться на 60 минут, чтобы селект всегда имел выделенный вариант.

#### Scenario: Выбор из списка
- **WHEN** в форме выбрана длительность 75 минут
- **THEN** урок сохраняется с длительностью 75

#### Scenario: Значение вне списка
- **WHEN** отправлена форма с длительностью 80 минут
- **THEN** урок не создаётся, форма показывает ошибку

#### Scenario: Длительность по умолчанию из профиля
- **WHEN** в профиле задана длительность урока по умолчанию 45 минут и открыта форма создания урока без параметра `duration_min`
- **THEN** в селекте «Длительность» выделено 45 минут

#### Scenario: Настройка не задана
- **WHEN** репетитор ещё не сохранял настройки профиля и открыта форма создания урока
- **THEN** в селекте «Длительность» выделено 60 минут

#### Scenario: Некорректная настройка
- **WHEN** в настройках профиля лежит длительность 61 минута (значение вне списка)
- **THEN** в селекте «Длительность» выделено 60 минут, ошибки нет

#### Scenario: Префилл из окна важнее настройки
- **WHEN** в профиле задано 45 минут, а форма создания открыта по адресу `/tutor/lessons/new?duration_min=90`
- **THEN** в селекте «Длительность» выделено 90 минут

#### Scenario: Редактирование не затрагивается
- **WHEN** в профиле задано 45 минут и открыта форма редактирования урока длительностью 90 минут
- **THEN** в селекте «Длительность» выделено 90 минут — длительность самого урока

### Requirement: Создание урока
Кнопка «Создать урок» SHALL открывать модальное окно «Новый урок» с полями: выбор ученика (или группы), заметка к занятию, ссылка на встречу, начало (обязательное), длительность, переключатель «Повторять урок», тип урока, оплата ученика (скрыта для группового типа) и кнопки «Закрыть» и «Сохранить». После сохранения окно закрывается, урок появляется в списке. Форма SHALL открываться с префиллом начала (см. «Форма создания принимает префилл начала»), в том числе из календаря, и с предвыбранной длительностью из настроек профиля, если длительность не задана параметром (см. «Поле длительности»).

#### Scenario: Успешное создание
- **WHEN** отправлена валидная форма создания урока
- **THEN** урок создан со статусом «Запланирован», окно закрытось, строка урока появилась в списке

#### Scenario: Пустое начало
- **WHEN** отправлена форма без начала урока
- **THEN** урок не создаётся, поле начала подсвечено как обязательное

#### Scenario: Создание из календаря
- **WHEN** форма создания открыта из календаря с префиллом и сохранена
- **THEN** урок создан, окно закрылось, неделя календаря обновлена и урок виден в слоте

#### Scenario: Длительность по умолчанию при создании
- **WHEN** форма создания открыта без параметра `duration_min` при сохранённой в профиле длительности 45 минут
- **THEN** форма открыта с выделенной длительностью 45 минут, и сохранение без правки создаёт урок на 45 минут
