# Proposal

## Why

На вкладке «ДЗ» есть кнопка «Прикрепить файл», но за ней ничего не стоит: файлы
не загружаются, не сохраняются и не отдаются — репетитор и ученик обмениваются
только ссылками на внешние облака. Ссылка живёт, пока владелец не закроет доступ,
файл может исчезнуть или стать публичным, а репетитор не может положить к заданию
условие задачи в PDF или фото страницы учебника.

Нужна собственная загрузка файлов: метаданные в БД, сами байты — в хранилище,
которое выбирается конфигурацией (локальный диск сервера или S3-совместимый
бакет). Для S3 ссылка на скачивание должна быть временной, чтобы приватный бакет
не отдавал файл по угаданному адресу.

## What Changes

- В ядре появляется модуль `app/files/`: модель метаданных файла, абстракция
  хранилища с двумя реализациями (локальный диск и S3), фабрика по env,
  валидация загрузки, доступ к скачиванию.
- Выбор бэкенда — переменная окружения `FILES_BACKEND` (`local` по умолчанию или
  `s3`). Локальный бэкенд пишет в `FILES_LOCAL_ROOT`, S3 — в бакет `S3_BUCKET`
  через `boto3` (`S3_ENDPOINT_URL` для MinIO/Selectel).
- Ограничения загрузки — тоже из env: `FILES_MAX_SIZE_MB` и
  `FILES_ALLOWED_EXTENSIONS`; нарушение даёт сообщение об ошибке в форме, файл не
  сохраняется.
- Скачивание: `GET /files/{file_id}`. Локальный бэкенд отдаёт файл самим
  приложением (проверка сессии, `Content-Disposition: attachment`, `nosniff`),
  S3-бэкенд — 302 на presigned URL с TTL `FILES_PRESIGN_TTL_SECONDS`.
- Вкладка «ДЗ»: кнопка-заглушка заменяется полем выбора файлов (несколько
  файлов сразу) и списком прикреплённых файлов с удалением. Файлы привязаны к
  записи ДЗ отдельной таблицей связи с порядком.
- Скачивание доступно репетитору-владельцу, ученику этого ДЗ (индивидуальный
  урок или группа с его участием) и родителю привязанного ребёнка; остальным —
  404, как у несуществующего файла.
- Удаление урока или серии снимает метаданные каскадом, а объекты в хранилище
  удаляются сервисом удаления до каскада.
- Схема БД: две новые таблицы (`files`, `homework_files`), одна миграция.

## Capabilities

### New Capabilities

- `file-storage`: бэкенды хранения, конфигурация через env, валидация загрузки,
  временные ссылки S3, изоляция доступа к скачиванию и удаление объектов.

### Modified Capabilities

- `homework-management`: требование «Поля ДЗ без файлов и автоматики» заменяется
  загрузкой, показом, скачиванием и удалением файлов ДЗ; чекбокс «Учитывать
  дедлайн» по-прежнему только сохраняется.

## Impact

- **Новый модуль**: `app/files/` — `models/`, `services/`, `views/`,
  `templates/`.
- **Изменённые модули**: `app/config.py` (поля и валидатор), `app/models.py`
  (регистрация моделей), `app/templating.py` (хелпер размера файла),
  `app/homework/` (форма панели, вьюха сохранения, контекст панели, шаблон),
  `app/cabinet/` (карточки ДЗ ученика и родителя), `app/lesson/services/
  lesson_remover.py` (уборка объектов до каскада), `main.py` (роутер).
- **Зависимости**: `boto3` в `pyproject.toml` и `uv.lock`.
- **Тесты**: `tests/test_file_storage.py`, `tests/test_file_upload.py`,
  правки `tests/test_homework.py`, `tests/test_cabinet_homework.py`.
- **Документация**: `README.md` (таблица конфигурации и раздел про хранение
  файлов), `CHANGELOG.md`.
- **Миграции**: одна (`files`, `homework_files`).
- **Вне объёма**: файлы в ответе ученика, загрузка из кабинета, антивирусная
  проверка, cron-уборка осиротевших объектов, прямая отдача S3 через свой домен.
