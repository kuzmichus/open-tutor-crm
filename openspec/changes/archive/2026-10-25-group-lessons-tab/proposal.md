# Proposal

## Why

Вкладка «Занятия» в модалке управления группой — заглушка «Занятия группы появятся позже», хотя уроки групп давно живут в модуле `lesson` (`lessons.group_id`). Репетитор, который ведёт группу, не может из карточки группы увидеть её занятия: когда они стоят, в каком статусе и что с домашними заданиями, — ему приходится идти на страницу «Уроки» и искать группу фильтром.

Спека `group-management` прямо требует заглушку («списки занятий не отображаются») — этот change снимает требование и заменяет вкладку реальным списком, как это уже сделано для вкладки «Оплаты» change'ом `group-payments-tab`.

## What Changes

- **Вкладка «Занятия» модалки группы показывает список занятий группы** вместо заглушки:
  - строка-карточка на каждое занятие: дата и интервал «17.05.2027 15:00–16:00» (в зоне педагога), чип статуса, описание группы (контекст предмета) и индикатор «ДЗ: есть/нет»;
  - порядок — свежие сверху (`starts_at` по убыванию);
  - чипы фильтра статуса: «Все» (по умолчанию), «Проведённые», «Запланированные»;
  - пустые состояния: без занятий — «У группы пока нет занятий.», с фильтром без совпадений — «Нет занятий с таким статусом.».
- **Панель приходит отдельным GET-маршрутом** `/tutor/groups/{id}/lessons` (партиал с корнем `#group-lessons-content`): вкладка грузится лениво из слота с `hx-trigger="load"`, чипы статуса перезапрашивают тот же маршрут, события `lesson-saved`/`homework-saved` перезапрашивают панель после действий в модалке урока (паттерн вкладки «Оплаты»).
- **Клик по занятию открывает стандартную модалку урока во втором слое** (`#modal-lesson`, `z-index` выше, design D10 `student-finance`): модалка группы со своими несохранёнными полями остаётся в `#modal`. htmx шлёт цель заголовком `HX-Target` — GET и POST формы урока возвращаются во второй слой, сохранение/удаление урока не вытесняет модалку группы.
- **Данные выбирает модуль `lesson`** (новый сервис `group_lessons`), владелец группы проверяется через ри-экспорт `get_owned_group` в `lesson/services/access.py`.
- **Сохранение ДЗ шлёт `HX-Trigger: homework-saved`** — индикатор «ДЗ: есть/нет» в списке группы не устаревает, пока модалка урока открыта поверх.
- **BREAKING для спек**: требование `group-management` «Заглушки вкладок «Расписание» и «Занятия»» сужается до вкладки «Расписание»; добавляется требование «Вкладка «Занятия» группы».

Вне объёма: создание занятия из модалки группы, пагинация, посещаемость, редактирование расписания группы.

## Capabilities

### Modified Capabilities

- `group-management`: вкладка «Занятия» модалки управления группы показывает список занятий группы с фильтром по статусу вместо заглушки; клик по занятию открывает модалку урока вторым слоем.

## Impact

- **Новое**: `app/lesson/services/group_lessons.py` (выборка + нормализация фильтра), `app/lesson/views/group_lessons.py` (GET-партиал), `app/lesson/templates/lesson/_group_panel.html`.
- **Изменённое**: `app/group/templates/group/_manage.html` (слот панели вместо заглушки), `app/group/templates/group/index.html` (контейнер `#modal-lesson`, скрипт `lessons.js`), `app/lesson/services/access.py` (ри-экспорт `get_owned_group`), `app/lesson/services/lesson_form.py` и `app/lesson/templates/lesson/_form.html` (`modal_target`), `app/lesson/views/update.py` (цель из `HX-Target`), `app/lesson/services/presentation.py` (`lesson_date`, `homework_short_label`), `app/homework/views/save.py` (триггер `homework-saved`), `app/lesson/views/__init__.py`, `app/static/styles.css` (блок `group-lessons`).
- **Миграций нет**: данные читаются из существующих `lessons` и `homework`.
- **Тесты**: `tests/test_group_lessons.py` (список, порядок, фильтры, ДЗ-индикатор, изоляция, второй слой); правки в `tests/test_group_manage.py` (заглушка — только «Расписание») и `tests/test_homework.py` (триггер `homework-saved`).
