# Proposal

## Why

Желаемая нагрузка в неделю показывает, сколько часов репетитор проводит за
уроками, но не учитывает время на подготовку к занятию и проверку домашних
заданий. Из-за этого реальная занятость оказывается заметно выше запланированной,
и репетитор переоценивает свободное время недели.

## What Changes

- В таблицу `tutor_settings` добавляется колонка `preparation_coefficient`
  (`Numeric(4, 2)`, NOT NULL, по умолчанию 0.70) и миграция.
- В карточке «Желаемая нагрузка» вкладки «Календарь» появляется второе поле
  «Коэффициент подготовки» с пояснением: это доля длительности урока, которая в
  среднем уходит на подготовку к занятию и проверку домашних заданий (при 0.7
  каждый час урока требует ещё около 42 минут).
- Значение — число от 0 до 5; по умолчанию 0.7. Пустое поле возвращает значение
  по умолчанию, некорректное — отклоняется с ошибкой на той же вкладке.
- Коэффициент пока нигде не используется в расчётах: это ориентир для
  планирования личного времени.

### Modified Capabilities

- `tutor-profile-settings`: требование «Вкладка «Календарь» хранит часовой пояс,
  учебный год и настройки уроков» расширяется — блок «Желаемая нагрузка»
  содержит два поля (нагрузка и коэффициент подготовки) и правила валидации
  коэффициента.
