# Proposal

## Why

В проекте нет модели уроков: пункт меню «Уроки» (`/tutor/lessons`) ведёт в 404, календарь работает на демо-данных, а спека `calendar` явно ждёт «модели занятий». Без таблиц уроков нельзя вести историю занятий, оплату, статусы и ДЗ — ядро CRM репетитора.

## What Changes

- Новый доменный модуль `app/lesson/` с моделями `Lesson` и `LessonSeries` (миграция Alembic).
- Страница `/tutor/lessons`: список уроков с поиском, фильтрами (чипы «Все/Сегодня/На этой неделе», фильтр по ученику), сортировкой «Сначала ближайшие», колонками «Ученик/Группа», «Дата и время», «Стоимость», «Оценка», «Статус».
- Модальное окно «Новый урок»: ученик/группа через единый селект с поиском и мини-формой создания на месте, тип урока (Индивидуальный/Групповой/Пробный/Отработка), начало, длительность из закрытого списка (15 значений), заметка, ссылка на встречу, оплата ученика, «Повторять урок» с панелью расписания.
- Редактирование урока: статус (Запланирован/Проведён), блок «Для семьи» (оценка ★ + комментарий), предупреждение при изменении цены проведённого урока, переключатель «Применить ко всей серии», кнопка «Серию» (массовое удаление серии).
- Серии: `LessonSeries` хранит слоты (день недели + начало/окончание), интервал в неделях и дату окончания; уроки материализуются при создании и связываются `series_id`.
- Вкладка «ДЗ» — неактивная заглушка в форме создания и редактирования (поля ДЗ вне scope).
- Вне scope: предмет, оплата учителя, учитель, место, финансы как сущность, перевод календаря с демо-данных, продление серии, цена в карточке ученика.

## Capabilities

### New Capabilities

- `lesson-management`: уроки репетитора — модель (тип, ученик XOR группа, начало, длительность, статус, оплата ученика, оценка/комментарий для семьи), страница списка с фильтрами, создание и редактирование через модальное окно, единый селект ученика/группы с мини-формой создания на месте, серии повторяющихся уроков (генерация, массовое редактирование, массовое удаление), доступ только владельцу и изоляция по репетитору.

## Impact

- **Код**: новый пакет `app/lesson/` (models, views, services, templates), подключение роутера в `main.py`, регистрация моделей в `app/models.py`, пункт сайдбара `/tutor/lessons` перестаёт быть 404.
- **БД**: миграция `alembic` — таблицы `lesson_series` и `lessons`.
- **Тесты**: новый `tests/test_lesson_*.py` (модели, генерация серии, страницы, доступ).
- **Зависимости**: переиспользуются существующие компоненты (селект «Добавить ученика», мини-форма ученика из `app/group/services/student_mini.py`).
