# Proposal

## Why

Срок сдачи домашнего задания педагог сейчас вводит руками, хотя почти всегда
это дата и время следующего занятия ученика (или группы): ДЗ задаётся на
уроке, а сдаётся к следующей встрече. Ввод повторяет данные, которые уже есть
в календаре, и ошибка в нём (не тот день, не то время) ломает напоминания и
виртуальный статус «Просрочено».

Задача TOCRM-62: при добавлении ДЗ к уроку автоматически подставлять в «Срок
сдачи» дату и начало времени следующего занятия, если оно есть.

## What Changes

- В панели ДЗ (вкладка «ДЗ» модалки редактирования урока) поле «Срок сдачи»
  предзаполняется началом ближайшего запланированного занятия ученика, если
  у урока ещё нет записи ДЗ. Для группового урока — началом ближайшего
  занятия той же группы.
- Под полем показывается подсказка «По умолчанию — начало следующего
  занятия»: значение можно изменить или очистить вручную.
- При первом сохранении ДЗ без указанного срока сервер подставляет то же
  значение сам — не полагаясь на браузер и клиентский JS (форма работает и
  без HTMX/JS).
- Существующая запись ДЗ не перезаписывается: срок, очищенный вручную,
  остаётся пустым при повторных сохранениях.
- «Следующее занятие» — только запланированный урок, который начинается
  позже текущего урока и не раньше текущего момента; проведённые и прошедшие
  занятия не учитываются.
- Схема БД не меняется: срок по умолчанию вычисляется из существующих
  уроков, новых полей и миграций нет.

**Вне области этого change:**

- Напоминания и автоматический статус по дедлайну: чекбокс «Учитывать
  дедлайн» по-прежнему только сохраняется.
- Автоматический перенос срока при переносе следующего занятия: срок —
  обычное поле ДЗ, после сохранения живёт сам по себе.
- Подстановка в форме создания урока: вкладки «ДЗ» там нет.

## Capabilities

### New Capabilities

— (нет)

### Modified Capabilities

- `homework-management`: добавляется требование «Срок сдачи по умолчанию —
  начало следующего занятия» с правилами выбора занятия и границами
  подстановки (только новая запись ДЗ).

## Impact

- **Сервисы**: новый `app/homework/services/due_default.py`
  (`next_lesson_start`); правки `homework_context.py` (подстановка в панели)
  и `homework_writer.py` (подстановка при создании записи).
- **Шаблоны**: `app/homework/templates/homework/_panel.html` — подсказка под
  полем «Срок сдачи».
- **Тесты**: `tests/test_homework.py` — юнит-тесты выбора следующего занятия
  и HTTP-тесты панели/сохранения.
- **Документация**: `README.md`, `CHANGELOG.md`, спека
  `homework-management`.
- **Схема БД и миграции**: не меняются.
