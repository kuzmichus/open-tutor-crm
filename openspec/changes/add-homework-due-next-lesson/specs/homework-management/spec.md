# Spec Delta

## ADDED Requirements

### Requirement: Срок сдачи по умолчанию — начало следующего занятия

При первом открытии панели ДЗ урока и при первом сохранении ДЗ без указанного
срока система SHALL подставлять в «Срок сдачи» дату и время начала
ближайшего следующего занятия, если оно есть. Для урока с учеником следующее
занятие SHALL искаться среди индивидуальных уроков этого ученика и групповых
уроков групп, в которых он состоит; для группового урока — среди уроков той же
группы. Учитываются только запланированные занятия, которые начинаются позже
текущего урока и не раньше текущего момента. Подстановка MUST NOT применяться
к уже существующей записи ДЗ: сохранённый или вручную очищенный срок остаётся
как есть. Срок SHALL храниться в UTC, а в поле показываться в зоне педагога.

#### Scenario: Подстановка в панели нового ДЗ
- **WHEN** у урока без записи ДЗ есть следующее запланированное занятие и
  открыта вкладка «ДЗ»
- **THEN** поле «Срок сдачи» заполнено датой и временем начала этого занятия
  в зоне педагога, под полем показана подсказка «По умолчанию — начало
  следующего занятия»

#### Scenario: Сохранение нового ДЗ без срока
- **WHEN** ДЗ впервые сохраняется с пустым полем «Срок сдачи», а следующее
  занятие запланировано
- **THEN** запись ДЗ создана со сроком сдачи, равным началу следующего
  занятия (в UTC)

#### Scenario: Следующего занятия нет
- **WHEN** у урока нет запланированного занятия позже него и открыта вкладка
  «ДЗ»
- **THEN** поле «Срок сдачи» пустое, подсказка о подстановке не показана

#### Scenario: Существующее ДЗ не перезаписывается
- **WHEN** у урока уже есть запись ДЗ с очищенным вручную сроком сдачи и ДЗ
  сохраняется повторно
- **THEN** срок сдачи остаётся пустым — подстановка выполняется только при
  создании записи

#### Scenario: Проведённые и прошедшие занятия не учитываются
- **WHEN** после текущего урока есть только проведённое занятие или занятие
  раньше текущего момента
- **THEN** срок сдачи не подставляется

#### Scenario: Групповой урок
- **WHEN** ДЗ добавляется к групповому уроку, у группы есть следующее
  запланированное занятие
- **THEN** срок сдачи подставлен из начала этого занятия группы
