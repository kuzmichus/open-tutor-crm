# Proposal

## Why

В карточке ученика нет даты рождения: репетитор не может записать её в CRM и
вынужден держать в заметках. При этом в настройках уведомлений уже есть флаг
«День рождения», которому неоткуда взять дату.

## What Changes

- В таблицу `students` добавляется необязательная колонка `birth_date` (`DATE`,
  NULL по умолчанию) и соответствующая миграция.
- В модальной форме карточки ученика на вкладке «Общее» появляется поле
  «Дата рождения» (`input type="date"`), доступное и ребёнку, и взрослому.
- Дата разбирается из ISO-строки `YYYY-MM-DD`; пустое значение сохраняется как
  NULL, некорректное — даёт сообщение «Дата рождения указана некорректно.»
  вместо ошибки 500.
- Страница карточки ученика показывает дату рождения в блоке «Данные ученика»
  в формате `ДД.ММ.ГГГГ` (без пересчёта в часовой пояс педагога — это
  календарный день, а не момент времени).
- Существующие ученики получают NULL; бэкфилл не нужен.

### Modified Capabilities

- `student-records`: в требовании «Состав карточки ученика» появляется дата
  рождения; добавляется требование «Дата рождения ученика» с правилами разбора,
  хранения и показа.

  показ даты в списке учеников.
