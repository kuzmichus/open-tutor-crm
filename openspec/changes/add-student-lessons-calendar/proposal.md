# Proposal

## Why

Вкладка «Мои уроки» кабинета ученика показывает таблицу ближайших занятий: пять
строк «дата — время — тип». По ней нельзя понять, как выглядит неделя — где окна
между уроками, насколько плотно расписание, что уже прошло. Календарь репетитора
(`/tutor/calendar`) отвечает ровно на эти вопросы, но он интерактивный: карточку
можно перетащить, клик по четверти открывает форму создания урока.

Ученику нужен тот же вид недели без единого действия, которое меняет данные:
он не переносит и не редактирует занятия.

## What Changes

- Таблица ближайших занятий в `/student` заменяется недельной сеткой (пн–вс) —
  визуальным компонентом календаря репетитора (`.cal-*`) в режиме только чтения.
- Карточка «Ближайшее занятие» остаётся: она отвечает на другой вопрос
  («когда следующий урок»), календарь — «как выглядит неделя».
- Карточка урока содержит интервал времени («10:00 – 10:40») и подпись занятия:
  слово «Урок» для индивидуального/пробного/отработки, название группы — для
  группового. Цена и имя ученика не показываются.
- Домашнее задание обозначается значком в карточке; цвет значка кодирует статус:
  «Задано» — нейтральный, «Сдано» — акцентный, «Проверено» — зелёный,
  «Не выполнено» — красный. Статус дублируется подсказкой (`title`, `aria-label`).
- Прошедшие и проведённые уроки показываются серым, но не исчезают: ученик видит
  неделю целиком.
- Листание недель (назад/вперёд/«Сегодня») работает обычными ссылками `?start=…`
  с подменой только области календаря через htmx; без JS работают те же ссылки.
- Календарь строго read-only: не подключается `calendar.js`, нет `hx-get` на формы
  урока, нет данных для drag, четверти часа пассивны, курсор карточки — `default`.
- Отметки недоступности репетитора (отпуск, выходные) ученику не показываются.

## Capabilities

### New Capabilities

— (нет)

### Modified Capabilities

- `student-cabinet`: требование «Кабинет: вкладка «Мои уроки»» переписано —
  вместо списка ближайших уроков недельный календарь только для чтения.
  Добавлены требования «Карточка урока в календаре ученика» и
  «Значок домашнего задания в календаре».

## Impact

- **Сервисы**: новый `app/cabinet/services/calendar.py` (выборка недели ученика,
  карта статусов ДЗ, сборка контекста поверх `calendar/services/presentation.py`);
  `app/cabinet/services/presentation.py` (класс и подпись значка ДЗ).
  `app/cabinet/services/lessons.py` не меняется — им пользуется кабинет родителя.
- **Вьюхи**: `app/cabinet/views/index.py` — параметр `?start=`, фрагмент для htmx.
- **Шаблоны**: новый `app/cabinet/templates/cabinet/_lessons_calendar.html`;
  `app/cabinet/templates/cabinet/lessons.html` (таблица удалена).
- **CSS**: `app/static/styles.css` — блок `.cabinet-calendar*`, `.cal-event--readonly`,
  `.cal-hw-badge*`. Общие правила `.cal-*` не меняются, чтобы не задеть календарь
  репетитора.
- **Тесты**: `tests/test_cabinet_pages.py` (страничные тесты кабинета),
  новый `tests/test_cabinet_calendar.py` (сервис и read-only разметка).
- **Вне объёма**: вкладка «Мои уроки» ребёнка в кабинете родителя
  (`/parent/students/{id}`) остаётся таблицей — отдельный change; легенда цветов
  ДЗ под календарём; показ отметок недоступности репетитора.
- **БД и миграции**: без изменений.
