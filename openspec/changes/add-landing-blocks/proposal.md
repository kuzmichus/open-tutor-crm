# Proposal

## Why

Редактор лендинга умеет загружать картинки в Asset Manager, но панель
«Блоки» пуста: ядро GrapesJS 0.23.9 не содержит ни одного блока. Репетитор,
открывший редактор, видит холст и должен собирать страницу вручную через
«Показать код» — визуальная правка фактически недоступна. При этом
типовые секции лендинга (шапка, обложка с CTA, «О себе», «Стоимость»,
«Контакты», подвал) уже описаны в шаблоне по умолчанию и повторяются у
каждого репетитора.

Нужно, чтобы основные блоки лендинга в дизайне CRM добавлялись в один
клик, а картинку можно было вставить из редактора, не заходя в код.

## What Changes

- Новый сервис `app/landing/services/blocks.py`: набор блоков GrapesJS —
  готовые секции лендинга (`header`, `hero`, `about`, `price`,
  `contacts`, `footer`) в категории «Блоки лендинга», простые элементы
  (`heading`, `text`, `image`, `button`, `divider`) в «Базовых» и
  раскладка (`column2`, `column3`) в «Макете».
- Секции используют классы и CSS-переменные шаблона по умолчанию, поэтому
  вставленный блок сразу выглядит как страница и переживает сохранение.
- CTA блоков «Обложка» и «Кнопка» ведёт на публичную страницу записи
  текущего репетитора (`/s/<tutor_id>`); адрес подставляет вьюха.
- `views/editor.py` передаёт набор блоков в шаблон редактора.
- `templates/landing/editor.html`: JSON `landing-blocks`, конфиг
  `blockManager: { appendOnClick: true, blocks }` — блок вставляется
  кликом, а не только перетаскиванием.
- Блок «Изображение» после вставки сразу открывает Asset Manager
  (`component:add` по маркеру `data-landing-image`): репетитор выбирает
  файл или загружает новый в том же действии. Пустой `src=""` в разметку
  не попадает.
- Русская локаль `i18n-ru.js`: подписи новых блоков и категории
  «Блоки лендинга».
- Тесты `tests/test_landing_blocks.py`: состав набора, категории, CTA,
  блок изображения, встраивание в редактор, подписи локали.

**Вне области:**

- Новые серверные роуты: загрузка и удаление картинок уже реализованы
  (`add-landing-assets`).
- Готовые «темы» и произвольные пользовательские блоки.
- Хранение блоков в БД: набор — статический сервис приложения.
