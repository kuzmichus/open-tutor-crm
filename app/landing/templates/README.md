# Шаблон лендинга по умолчанию

`default_page.html.j2` — самодостаточная одностраничная страница репетитора,
а `blocks/*.j2` — те же секции в виде блоков панели GrapesJS
(`app/landing/services/blocks.py`). Файлы правятся в исходнике; сама
страница репетитора редактируется визуально в `/tutor/landing/editor`.

## Что подставляется из профиля автоматически

При создании черновика («Создать черновик» / «Вернуть шаблон») шаблон
рендерится данными профиля репетитора:

| Значение | Откуда | Где на странице |
|---|---|---|
| Имя | профиль | шапка, `<title>`, копирайт |
| Предмет | профиль | подзаголовок обложки, `<title>`, description |
| О себе, опыт | профиль | секция «Обо мне», строка доверия |
| Ставка | профиль | первая карточка «Разовое занятие» |
| Телефон | профиль | пилюля в подвале (`tel:`) |
| `/s/<tutor_id>` | сервер | все CTA «Записаться на бесплатное пробное» |

Пустые поля скрывают свою секцию или элемент — пустых заголовков не бывает.

## Демо-контент: что заменить

Места замены помечены в исходнике комментариями `{# ДЕМО: … #}` (в
опубликованную страницу они не попадают). Демо-набор — «репетитор по
математике»:

1. **Оффер** — H1 обложки «Подготовлю к ЕГЭ по математике на 80+ за
   6 месяцев». Замените на конкретное обещание: предмет + срок +
   измеримый результат.
2. **Строка доверия** — «84 — средний балл ЕГЭ», «40+ учеников».
   Опыт подставляется из профиля.
3. **Цены пакетов** — абонемент «4 400 ₽» и интенсив «9 600 ₽» (в первой
   карточке ставка из профиля). Цены всегда явные, без «по запросу».
4. **Образование, курсы, сертификаты** — три пункта (вуз, курс,
   сертификат) с годами. Замените на свои.
5. **Отзывы** — три карточки с конкретными результатами. Замените
   реальными: цитата + имя + результат («ЕГЭ профиль — 85»).
6. **Шаги обучения** — формат (Zoom/офлайн), длительность, ДЗ, перенос.
7. **Ответы FAQ** — под ваши правила (оплата, перенос, «с двойками»).
8. **Ссылки мессенджеров** в подвале — `#`-плейсхолдеры; подставьте
   `https://t.me/…`, `https://wa.me/…`, `mailto:` и адрес политики
   конфиденциальности.

Править демо-контент удобнее в редакторе лендинга, а не в исходнике:
источник нужен только при пересборке шаблона для всех установок.

## Как менять цвета

Палитра — CSS-переменные в `<style>` шаблона (и они же используются
блоками):

- `--accent` — акцент (иконки, маркеры, рамка популярного пакета);
- `--accent-strong` / `--accent-strong-hover` — фон CTA и текстовых
  ссылок; в светлой теме темнее акцента ради контраста ≥ 4.5:1;
- `--cta-fg` — цвет текста на CTA (белый в светлой теме, графит в тёмной);
- `--bg`, `--surface`, `--text`, `--muted`, `--border` — поверхности и текст.

Тёмный набор объявлен дважды: в `:root[data-theme="dark"]` (ручной
переключатель) и в `@media (prefers-color-scheme: dark)` (системная тема
без скрипта). Меняя палитру, правьте оба набора; контраст текста с фоном
проверяйте на ≥ 4.5:1 (инструмент Lighthouse или любой контраст-калькулятор).

## Скрипты и что они переживают

- `landing-effects.js` — тема (localStorage + системная), проявление
  секций (`data-reveal`), `aria-expanded` аккордеона. Подключается без
  `defer`, чтобы поставить тему до первой отрисовки.
- `landing-auth.js` — подмена кнопок входа у вошедших.

Оба тега в конце `<body>` стоят в самом шаблоне и гарантируются сервером
при каждом сохранении из редактора (`draft_render.ensure_runtime_scripts`):
GrapesJS вырезает скрипты из тела, но теги возвращаются. Встраивать свои
скрипты в тело страницы нельзя — они не переживут первое сохранение;
выносите их в `app/static/` и добавляйте в `RUNTIME_SCRIPTS`.

## Ограничения CSS из-за редактора

GrapesJS разбирает стили браузерным CSSOM и выбрасывает сокращённые
свойства, если их часть задана через `var()` (`background: var(--bg)`,
`border: 1px solid var(--border)`). Разрешённые сокращения — `margin`,
`padding`, `border`, `border-radius`, `gap`, `background` (один цвет) —
их разворачивает `css_for_editor` при загрузке черновика. Во всех прочих
свойствах (`box-shadow`, `font-size`, `outline-color`, …) `var()`
использовать можно — это длинные свойства, CSSOM их сохраняет.
